# Multilingual Text Summarization Using Transformer Models

## Project Overview
This project focuses on developing an AI-powered multilingual text summarization system using transformer-based deep learning models from Hugging Face.

The system generates concise and meaningful summaries from documents in multiple languages.

## Supported Languages
- English
- Hindi
- Telugu

## Objectives
- Develop a multilingual document summarization system.
- Fine-tune transformer-based summarization models.
- Compare multiple models using evaluation metrics.
- Identify the most suitable model for summarization.
- Generate summaries in the user's selected language.

## Technologies Used
- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- NLP
- Deep Learning

## Dataset
XLSum Dataset (English, Hindi, and Telugu).

## Evaluation Metrics
- ROUGE-1
- ROUGE-2
- ROUGE-L

## Key Features
- Multilingual text summarization.
- Transformer model training and evaluation.
- Model performance comparison.
- Document-based summary generation.
- Language-specific summarization.

## Project Repository
The Jupyter Notebook contains the implementation of dataset preparation, model training, evaluation, and summarization.
